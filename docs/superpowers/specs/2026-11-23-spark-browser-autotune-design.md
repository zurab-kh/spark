# Spark — перехват из браузера и автоподбор соединений (дизайн, утверждён 2026-11-23)

## Зачем
Пользователь хочет, чтобы Spark был ещё быстрее и удобнее: (1) клик по ссылке на файл в браузере сразу качает через Spark;
(2) число соединений подбирается само, а не фиксированные 16.

## Подходы
- Перехват: **расширение MV3 + native messaging** (выбрано) — перехватывает обычный клик, передаёт cookies/Referer;
  альтернатива «только пункт контекстного меню» отвергнута — не перехватывает клик.
- Автоподбор: **ступенчатое наращивание по замеру скорости** (выбрано); альтернатива — фиксированное число — текущее поведение.

## 1. Перехват из браузера (Chrome, Edge)
- Расширение `browser-extension/` (Manifest V3, service worker). `chrome.downloads.onCreated`: если перехват включён,
  файл ≥ 1 МБ (или размер неизвестен), протокол http/https, и не была зажата Alt (content script отслеживает Alt+клик
  и сообщает воркеру) — `chrome.downloads.cancel` + `erase`, затем отправка в native host:
  `{ url, referer, fileName, cookies }` (cookies — `chrome.cookies.getAll({url})` → `name=value; …`).
  Если native host недоступен — загрузка НЕ отменяется (браузер качает сам).
- Иконка расширения — логотип Spark; всплывающее окно: переключатель «Перехватывать загрузки», статус связи со Spark.
- Native host: `Spark.exe --native-host` — читает сообщения native messaging (4 байта длины LE + UTF-8 JSON) из stdin,
  отвечает `{ "ok": true|false }`, передаёт ссылку через существующий `IpcClient`/`IpcProtocol` (поля url/referer/cookies/fileName
  уже есть). Если Spark не запущен — запускает `Spark.exe` и повторяет отправку (до ~5 с). Без окна.
- Регистрация: при каждом запуске Spark пишет манифест `com.spark.downloader.json` рядом с exe
  (path = текущий Spark.exe, allowed_origins = chrome-extension://<ID>/) и ключи
  `HKCU\Software\Google\Chrome\NativeMessagingHosts\com.spark.downloader` и `HKCU\Software\Microsoft\Edge\NativeMessagingHosts\com.spark.downloader`.
  ID расширения фиксируется ключом `key` в manifest.json.
- Публикация кладёт папку `browser-extension` рядом со `Spark.exe`. Установка — один раз вручную через «Загрузить распакованное».
- Настройки Spark: «Перехватывать загрузки браузера» (вкл. по умолчанию) — Spark игнорирует входящие ссылки из native host, когда выключено
  (расширение получает `ok:false` и не отменяет загрузку).

## 2. Автоподбор соединений
- Режим «Авто» (по умолчанию): старт с 8 соединений; каждые 3 с, если загрузка не в хвосте (осталось ≥ 8 МБ) и скорость за
  последний интервал выросла ≥ 10% относительно интервала до последнего добавления — добавить 4 (новые воркеры крадут куски),
  максимум 32; если рост < 10% — зафиксировать (больше не добавлять). Потолок хоста (HostLimits) по-прежнему ограничивает.
- Ручной режим: фиксированное число 1–32, как сейчас.
- `EngineOptions.ConnectionsPerFile = 0` означает «Авто»; `AppSettings.ConnectionsPerFile = 0` — «Авто» (по умолчанию).
- Тесты: сервер с лимитом на соединение → доходит до 32 и быстрее фиксированных 8; сервер с MaxConcurrent 6 → не выше 6, без ошибок.

## Не цели
